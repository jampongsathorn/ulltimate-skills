# Grill Me

Call the Skill tool with "grilling".

In Arena (which has no Skill tool), read `skills/grilling/SKILL.md` directly and follow it.

## Why this exists

`grill-me` is the trigger phrase users remember. `grilling` is the implementation. This file exists so both `/ulltimate-skills:grill-me` and `/ulltimate-skills:grilling` work in Claude Code, and so `npx skills add mattpocock/skills --skill=grill-me` users find a familiar name here.

Follow the full workflow in `../grilling/SKILL.md`.
