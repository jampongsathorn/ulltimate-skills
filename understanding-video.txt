PART 0 — หลักการ 8 ข้อ (อ่านก่อน ไม่งั้นพลาดเหมือน session 1)
================================================================================
1. PROBE ก่อนลงมือ — อย่าเดาว่าเน็ตเปิด/เครื่องมือมี ให้ทดสอบจริงก่อน (Step 0)
2. CHEAPEST FIRST — ลองวิธีถูกที่สุดก่อน (metadata endpoint) ก่อนสร้าง CI
3. ESCALATE อย่าสู้กับทางปิด — ถ้าดึงไฟล์ตรงไม่ได้ ให้ย้ายงานไป CI runner
4. ได้ของเร็ว > สมบูรณ์แบบ — one successful end-to-end run ก่อน ค่อยอัปเกรด
5. CROSS-VALIDATE — ทุกข้อสรุปต้องมีหลักฐาน 2 ทางอิสระ (ภาพ + OCR + เสียง + คำพูด)
6. แยก "ข้อเท็จจริง" ออกจาก "การตีความ"; จุดที่ไม่ชัดใส่ (?) อย่าเดาแทน user
7. HYGIENE — ไฟล์ใหญ่ไม่เข้า main; ของชั่วคราวต้องลบ; รายงานของค้างให้ user
8. ส่ง ARTIFACT ไม่ส่งแค่ข้อความ — user ต้องตรวจซ้ำได้โดยไม่ต้องเชื่อ agent

PART 2 — ทำในเครื่อง (หลังมีไฟล์วิดีโอใน workspace)
================================================================================
ตั้งค่าโฟลเดอร์ (convention ที่ใช้จริง):
    video-analysis/
    ├── video-content-report.md      ← รายงานสุดท้าย
    ├── media/source_video.mp4, media/audio.mp3
    ├── frames/f001..f0NN.jpg        ← เฟรมทุก 2 วิ
    ├── contact-sheets/sheet_*.jpg   ← ตารางภาพ 10 เฟรม/แผ่น
    ├── transcripts/*.txt
    └── evidence/                    ← probe, ocr, audio_stats, logs

STEP 2.1 — หา ffmpeg/ffprobe (เครื่อง sandbox มักไม่มี และ apt ถูกบล็อก)
    pip install -q --user --break-system-packages imageio-ffmpeg
    FF=$(python3 -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())")
    "$FF" -version        # พิสูจน์ว่าใช้ได้ (พิสูจน์แล้วว่า pypi ผ่าน)
    หมายเหตุ: imageio-ffmpeg ให้ ffmpeg แต่ **ไม่มี ffprobe** — ถ้าต้องการ metadata
             ให้อ่านจาก audio/video filter ("$FF" -i ... 2>&1) หรือใช้ CI

STEP 2.2 — Metadata
    "$FF" -hide_banner -i media/source_video.mp4 2>&1 | grep -E "Duration|Stream|bitrate"
    เก็บผลลง evidence/probe.txt

STEP 2.3 — เฟรม + contact sheet (ภาพคือหลักฐานหลัก)
    mkdir -p frames contact-sheets
    "$FF" -hide_banner -loglevel error -i media/source_video.mp4 -vf "fps=1/2" -q:v 2 frames/f%03d.jpg
    # ตารางภาพไว้กวาดตาทีเดียว (10 เฟรม = 20 วิ/แผ่น)
    "$FF" -hide_banner -loglevel error -i media/source_video.mp4 -vf "fps=1/2,scale=180:-2,tile=5x2" -q:v 3 contact-sheets/sheet_%02d.jpg
    # แล้วอ่านภาพด้วย read_file (ตัว agent เห็นภาพได้) — อ่าน contact sheet ก่อน แล้วซูมเฟรมที่สงสัย
    ⚠ ข้อจำกัดที่ต้องเขียนในรายงาน: ช็อตสั้นกว่า 2 วิ อาจตกหล่น

STEP 2.4 — เช็คลักษณะเสียง (สำคัญ! บอกว่าเป็น ASMR bed หรือมีช่วงเงียบ)
    "$FF" -hide_banner -loglevel error -i media/source_video.mp4 -vn -ac 1 -ar 16000 -y /tmp/a.wav
    pip install -q --user --break-system-packages numpy
    # ดูเฉลี่ย RMS + spectral flatness ต่อ 0.5 วิ (สคริปต์เต็มใน PART 3 / audio_stats)
    ผลที่ได้จริงในเคสตัวอย่าง: RMS ~72–79 dB ทุกช่วง **ไม่มีความเงียบเลย 99 วิ**
    flatness มัธยฐาน 0.375 → เสียงคนพูด + เสียงประกอบ/ASMR ตลอดคลิป
    ➜ ทำไมสำคัญ: ถ้าเห็น "ไม่เงียบเลย" แปลว่า whisper แบบใช้ VAD จะ **ตัดทิ้งครึ่งคลิป** (เจอจริง)

STEP 2.5 — OCR ตัวอักษรบนจอ (ถ้ามีแคปชันเบิร์นอิน)
    ต้องมี binary tesseract (apt) → ใน sandbox ที่ apt ถูกบล็อก ให้ทำใน CI (PART 3 Step 3.5)
    ถ้ามี tesseract ไทย:
      ตัดเฉพาะแถบล่าง 38% แล้วขยาย 2 เท่า + เพิ่มคอนทราสต์ ก่อน OCR (เพิ่มอัตราถูกมาก)
      "$FF" -hide_banner -loglevel error -i media/source_video.mp4 \
        -vf "fps=1,crop=iw:ih*0.38:0:ih*0.62,scale=iw*2:ih*2,eq=contrast=1.6:brightness=0.05,unsharp=5:5:1.2" \
        -q:v 2 /tmp/band/b%03d.jpg
      tesseract <frame> - -l tha --psm 6   (ลอง psm 6 และ 11 แล้วนับข้อความที่ซ้ำ)

STEP 2.6 — ถอดเสียงเป็นข้อความ (transcript)
    ⚠ FASTER-WHISPER ดาวน์โหลดโมเดลจาก HuggingFace → **ใน sandbox ที่ HF ถูกบล็อกจะทำไม่ได้**
      (พิสูจน์แล้ว: huggingface.co = SSLZeroReturnError) ➜ ให้ถอดใน CI (PART 3) หรือขอไฟล์ transcript จาก CI
    ถ้าทำได้ในเครื่อง (เน็ตเปิด/HF ผ่าน):
      pip install -q --user --break-system-packages faster-whisper
      - ใช้ ladder: large-v3-turbo → medium → small (large-v3 เปล่า **ช้ามาก** บน CPU, เคยค้าง 30+ นาที)
      - ตั้ง language="th" เสมอถ้าเป็นคลิปไทย (ไม่งั้นโมเดลสลับภาษาเพี้ยน)
      - ตั้ง condition_on_previous_text=False กัน hallucination ลามทั้งคลิป
      - รัน 2 แบบ: vad_filter=False และ True แล้วเทียบ (VAD จะตัด ASMR ทิ้ง → บทพูดหายครึ่ง)
      - ถ้าดนตรี/เสียงประกอบดังทับเสียงพูด ➜ **แยกเสียงร้องก่อนด้วย demucs** แล้วถอดจาก vocals
        (ในเคสจริง: demucs ทำให้ได้บทพูดครบและตรงขึ้นชัดเจน)
      - เก็บทุกเวอร์ชันไว้ใน transcripts/ แล้วเลือกตัวที่เชื่อถือได้เป็นหลัก

STEP 2.7 — Cross-validate (ขาดไม่ได้)
    ทำตารางเทียบ 4 ทาง: ภาพ(เฟรม) | ตัวอักษรบนจอ(OCR) | คุณสมบัติเสียง(spectrum) | คำพูด(transcript)
    - คำพูดกับภาพขัดกันไหม (เช่น คนในภาพชาย แต่ voice-over หญิง) ➜ **รายงานทั้งสอง ไม่เลือกเอง**
    - ตัวเลขที่ได้ยินไม่ตรงกัน (เช่น "18 วัน" vs "15 วัน") ➜ รายงานทั้งคู่พร้อม timestamp
    - สินค้าในแคปชันปรากฏในภาพจริงไหม (เคสจริง: **ไม่ปรากฏ**) ➜ เขียนระบุตรง ๆ
    - มีป้าย/สติกเกอร์ลิงก์ขายบนจอไหม ➜ ถ้าไม่มี ให้บอกว่า "ลิงก์อยู่ในแคปชันเท่านั้น"

STEP 2.8 — เขียนรายงาน (video-content-report.md)
    โครงที่ใช้ได้: 1) TL;DR 2) ข้อมูลเทคนิค 3) Shot list ตามเวลา
    4) Transcript เป็นตาราง [เวลา | ข้อความ] 5) โครงสร้างการเล่าเรื่อง/แกะสูตร
    6) ข้อจำกัดของรายงาน 7) ลิสต์ไฟล์ artifact 8) หมายเหตุการทำงาน+ของค้าง
    กติกา: ทุกข้อความอ้าง timestamp, จุดไม่ชัดใส่ (?), ห้ามเขียนสิ่งที่ไม่มีหลักฐานรองรับ

STEP 2.9 — ส่งมอบ
    present_file(video-content-report.md) + แนบ media/audio.mp3 ให้ user ฟังยืนยันบทพูด

PART 3 — CI RELAY (GitHub Actions เป็น "เครื่องมือดึงข้อมูล" เมื่อ egress ถูกบล็อก)
================================================================================
แนวคิด: sandbox แตะ github.com ได้ → ใช้ repo เป็นท่อ: runner ดาวน์โหลด+วิเคราะห์ แล้ว push
        artifact ขึ้น branch ชั่วคราว → sandbox git fetch กลับ
เงื่อนไข: repo สาธารณะ, App ของ Arena มีสิทธิ์ workflows + contents:write
         (ในเคสจริง: push ไฟล์ workflow ผ่านได้เลย)

⚠ สัญญาการเก็บกวาด (Cleanup contract) — ทำก่อนเริ่ม และทำทันทีที่จบ
   [] ลบ workflow ชั่วคราวออกจาก branch งาน
   [] ลบ branch ชั่วคราวทุกตัว (git push origin --delete <branch>)
   [] เช็คว่า "push ได้ก่อนเริ่มงานยาว" — **token อาจหมดอายุกลางทาง** (เจอจริง 401)
      ถ้าหมดอายุ: แจ้ง user ให้ reconnect GitHub แล้วค่อยเก็บกวาด (อย่าเงียบ)
   [] branch ชั่วคราวต้องมีชื่อเฉพาะต่อ run กันชนกัน: <prefix>-${{ github.run_number }}

STEP 3.1 — ไฟล์ .github/workflows/tmp-fetch-video-artifacts.yml (คัดจากของจริงที่รันผ่าน)
--------------------------------------------------------------------------------
name: tmp-fetch-video-artifacts
on:
  push:
    paths: ['.github/workflows/tmp-fetch-video-artifacts.yml']
  workflow_dispatch:
permissions:
  contents: write
env:
  OUT_BRANCH: tmp-video-artifacts-${{ github.run_number }}
  VID_720: '<URL mp4 720p จาก metadata>'
  VID_480: '<URL mp4 480p สำรอง>'
jobs:
  fetch:
    runs-on: ubuntu-latest
    timeout-minutes: 40
    steps:
      - uses: actions/checkout@v4
      - name: Install tooling
        run: |
          set -x
          mkdir -p out
          sudo apt-get update -qq
          sudo apt-get install -y -qq ffmpeg tesseract-ocr tesseract-ocr-tha
      - name: Download source video
        run: |
          set -x
          UA='Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0 Safari/537.36'
          ok=0
          for u in "$VID_720" "$VID_480"; do
            if curl -fsS -L --retry 3 -A "$UA" -o /tmp/v.mp4 "$u"; then ok=1; break; fi
          done
          [ "$ok" = "1" ] || exit 1
          cp /tmp/v.mp4 out/source_video.mp4
      - name: Extract caption band for OCR
        run: |
          mkdir -p out/band
          ffmpeg -hide_banner -loglevel error -i /tmp/v.mp4 \
            -vf "fps=1,crop=iw:ih*0.38:0:ih*0.62,scale=iw*2:ih*2,eq=contrast=1.6:brightness=0.05,unsharp=5:5:1.2" \
            -q:v 2 out/band/b%03d.jpg
      - name: OCR burned-in Thai captions
        continue-on-error: true
        run: |
          : > out/ocr_raw.txt
          for f in out/band/*.jpg; do
            echo "### $(basename "$f" .jpg)" >> out/ocr_raw.txt
            for psm in 6 11; do tesseract "$f" - -l tha --psm $psm 2>/dev/null | sed 's/^/  /' >> out/ocr_raw.txt || true; done
          done
      - name: Extract frames + contact sheets
        run: |
          mkdir -p out/frames
          ffprobe -v error -show_streams -show_format /tmp/v.mp4 > out/probe.txt 2>&1 || true
          ffmpeg -hide_banner -loglevel error -i /tmp/v.mp4 -vf "fps=1/2" -q:v 2 out/frames/f%03d.jpg
          ffmpeg -hide_banner -loglevel error -i /tmp/v.mp4 -vf "fps=1/2,scale=180:-2,tile=5x2" -q:v 3 out/sheet_%02d.jpg
          ffmpeg -hide_banner -loglevel error -i /tmp/v.mp4 -vn -ac 1 -ar 24000 -b:a 48k -y out/audio.mp3
      - uses: actions/setup-python@v5
        with: { python-version: '3.11' }
      - name: Audio profile (speech vs non-speech)
        continue-on-error: true
        run: |
          pip install -q numpy
          ffmpeg -hide_banner -loglevel error -i /tmp/v.mp4 -vn -ac 1 -ar 16000 -y /tmp/a.wav
          python3 - <<'PY' | tee out/audio_stats.txt
          import numpy as np, wave
          w=wave.open('/tmp/a.wav'); sr=w.getframerate(); n=w.getnframes()
          x=np.frombuffer(w.readframes(n),dtype=np.int16).astype(np.float32)/32768.0
          win=sr//2
          print("dur=%.2fs sr=%d"%(n/sr,sr)); print(" t(s)   rms_dB  centroid_kHz  flatness  zcr")
          for i in range(0,len(x)-win,win):
              seg=x[i:i+win]
              spec=np.abs(np.fft.rfft(seg*np.hanning(len(seg))))+1e-9
              freqs=np.fft.rfftfreq(len(seg),1/sr)
              cent=float(np.sum(freqs*spec)/np.sum(spec))
              flat=float(np.exp(np.mean(np.log(spec)))/np.mean(spec))
              zcr=float(np.mean(np.abs(np.diff(np.sign(seg)))))
              rms=20*np.log10(np.sqrt(np.mean(seg**2))+1e-9)
              print("%5.1f  %6.1f  %10.2f  %8.4f  %5.3f"%(i/sr,rms,cent/1000,flat,zcr))
          PY
      - name: Transcribe (demucs vocals + faster-whisper)
        continue-on-error: true
        run: |
          pip install -q faster-whisper demucs
          ffmpeg -hide_banner -loglevel error -i /tmp/v.mp4 -vn -ac 1 -ar 16000 -y /tmp/a.wav
          VOCALS=/tmp/a.wav
          python -m demucs --two-stems=vocals -n htdemucs -o /tmp/demucs /tmp/v.mp4 > out/demucs.log 2>&1 || true
          if [ -f /tmp/demucs/htdemucs/vocals.wav ]; then
            ffmpeg -hide_banner -loglevel error -i /tmp/demucs/htdemucs/vocals.wav -af "loudnorm=I=-18:TP=-1.5:LRA=11" -ar 16000 -ac 1 -y /tmp/vocals.wav
            VOCALS=/tmp/vocals.wav
          fi
          cat > /tmp/tr.py <<'PY'
          import os
          from faster_whisper import WhisperModel
          SRC=os.environ.get("VOCALS","/tmp/a.wav")
          def run(model, tag, audio, vad):
              segs, info = model.transcribe(audio, language="th", beam_size=5,
                  condition_on_previous_text=False, temperature=[0.0,0.2,0.4,0.6],
                  no_speech_threshold=0.6, repetition_penalty=1.15,
                  vad_filter=vad, vad_parameters=dict(min_silence_duration_ms=500) if vad else None)
              rows=["[%7.2f-%7.2f] %s"%(s.start,s.end,s.text.strip()) for s in segs]
              open("out/transcript_%s.txt"%tag,"w",encoding="utf-8").write("\n".join(rows)+"\n")
              print("\n".join(rows))
          m=None
          for name in ("large-v3-turbo","medium"):
              try: m=WhisperModel(name,device="cpu",compute_type="int8",cpu_threads=4); break
              except Exception as e: print("model failed",name,e)
          if m: run(m,"vocals_novad",SRC,False); run(m,"mix_novad","/tmp/a.wav",False)
          PY
          VOCALS="$VOCALS" timeout 1500 python /tmp/tr.py || echo "time budget reached"
      - name: Publish artifacts to throwaway branch
        if: always()
        run: |
          git config user.name "arena-artifact-bot"
          git config user.email "arena-artifact-bot@users.noreply.github.com"
          git checkout -b "$OUT_BRANCH"
          git add -f out
          git commit -m "tmp: video artifacts" || echo "nothing to commit"
          git push -u origin "$OUT_BRANCH" || git push --force origin "$OUT_BRANCH"

STEP 3.2 — เอา URL ไฟล์วิดีโอมาก่อน (ทำในเครื่อง ไม่ต้องใช้ CI)
    # metadata ทวีต X/Twitter ฟรี ไม่ต้องมี API key — ได้ caption, ไฟล์ mp4 ทุก bitrate, จำนวนวิว
    curl -sS "https://cdn.syndication.twimg.com/tweet-result?id=<TWEET_ID>&lang=th&token=a"
    curl -sS "https://api.fxtwitter.com/<user>/status/<TWEET_ID>"
    ⚠ ต้องระวัง: URL เปลี่ยนได้/ต้องใส่ ?tag=29; ถ้า 403 ให้ใช้ variant อื่น (720→480→320p)
    ⚠ ก่อนใช้ curl เช็คเน็ตก่อน 1 บรรทัด:

STEP 3.3 — push workflow → runner วิ่งอัตโนมัติ (push = trigger)
